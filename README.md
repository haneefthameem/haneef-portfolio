# Haneef Thameem - Portfolio Website

A modern, colorful, and responsive portfolio website showcasing electrical engineering expertise.

## 🚀 Features

- **Modern Design**: Gradient backgrounds, glassmorphism effects
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile
- **Smooth Animations**: Scroll animations and hover effects
- **Easy Navigation**: Smooth scrolling between sections
- **Professional Sections**: About, Experience, Skills, Projects, Contact

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Font Awesome Icons

## 📦 Installation & Setup

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/YOUR-USERNAME/haneef-portfolio.git
cd haneef-portfolio
```

2. Open in browser:
   - Simply open `index.html` in your web browser
   - Or use Live Server in VS Code for hot reload

### Using Python HTTP Server

```bash
python -m http.server 8000
```
Then open: http://localhost:8000

### Using Node.js HTTP Server

```bash
npx http-server
```

## 🌐 Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Push your code:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/haneef-portfolio.git
git push -u origin main
```

3. Go to repository Settings → Pages
4. Select `main` branch as source
5. Your site will be live at: `https://YOUR-USERNAME.github.io/haneef-portfolio/`

## 🎨 Customization

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-cyan: #06b6d4;
    --primary-blue: #3b82f6;
    /* Add your custom colors */
}
```

### Add New Section
1. Add HTML section in `index.html`
2. Add navigation link
3. Style in `styles.css`
